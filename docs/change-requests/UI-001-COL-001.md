# UI-001/COL-001 — collapsed columns and unreadable actions

31 October 2026. User-reported DEV251 visual regression. Production is on HOLD.
The user selected the website companion for a later approved cutover; that is
not an authorization to deploy or activate it now.

Baseline: deployed DEV251, source `8f722679c92eabcd2efb6cef824d5225b28dbcf4`,
archive `749f077d323d846c9e468aafe5ef31f1d215eed9afdde98baca9c8bc5e12178a`,
migration 159. Correction candidate: DEV252.

## Cause and missed verification

The Customer register has seven columns, but inherited six-column percentage
widths already consumed 100% before its Action column. Shared `overflow-wrap:
anywhere` and zero minimum widths allowed the action text to shrink to individual
characters. At the user's 2684-pixel width, the exact DEV251 styles reproduce a
17-line action and a 449-pixel row. Document-level horizontal overflow remains
false, so the previous overflow-only check incorrectly passed this layout.

## Presentation-only correction

- Allocate all seven Customer columns explicitly and reserve readable action
  space. Keep the complete register visible at the standard desktop breakpoint;
  use table-local scrolling at smaller widths.
- Show the existing record command as compact **Open**, retaining its complete
  accessible name, original handler and keyboard row activation.
- Reserve space for action cells across tables; preserve word boundaries in
  headers and controls. Never wrap a control into individual characters.
- Put previously unwrapped tables in the existing table-scroll component without
  replacing their nodes, form values or handlers.
- Make Administration entry grids adapt to their available width. The stronger
  audit found and corrected bare-table overflow in Company profile, SLA and
  Controlled document templates, plus desktop overflow in the routing form.

No API, SQL migration, workflow command, access rule, customer data or provider
configuration is changed by this correction. Package/version assertions change
only to identify the corrective candidate accurately.

## Verification

Five widths: 2684, 1920, 1280, 768 and 390 pixels. Assertions cover the working
content container as well as the document, action-control line count, Customer
action width/row height, preserved accessible action name and keyboard opening.
The focused regression fails against exact DEV251 and passes against DEV252.

The actual frontend rendered against read-only synthetic APIs passed the core
111-view/83-drill-down audit and the additional 41 Administration/Accountant
maintenance/category views. These are source checks, not live Test acceptance.
The governed regression passed 1,496 tests, with 93 deliberate skips and zero
failures. The mandatory isolated GitHub-origin build will repeat regression.

DEV251's earlier visual acceptance is superseded by this defect. Keep production
held. Before a corrected Test deployment: exact candidate approval, fresh paired
recovery, mandatory origin packaging/provenance verification, and exact-root
worker checks before restart and after readiness. Repeat live layout review with
populated data after deployment; do not substitute a no-overflow result for a
readability check.

### Assignment queue follow-up

User screenshots also identified the Manager/Director assignment queue. The
previous audit did not exercise its populated table. The correction now makes
that queue fill the viewport, reserves a readable Assign column, and keeps wide
tables inside their own horizontal scroller on small screens. Assignment rules,
requests and permissions are unchanged. Forty synthetic queue records exercise
both roles at all five widths, including vertical scrolling and opening then
closing the individual assignment dialog back to the queue. The working-screen
audit also checks scroll-to-bottom/top and restores the original scroll position;
dashboard drill-down checks assert Close returns to the dashboard controls.

This is a source correction, not evidence of a hosted deployment. CRM Test still
serves DEV251 until the exact revised package is approved and installed.
